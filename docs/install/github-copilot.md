# GitHub Copilot

```bash
./install.sh --tool copilot --target ../my-repo
```

The installer writes:

- `.github/copilot-instructions.md`
- `.github/instructions/the-team-loop.instructions.md`
- `.github/copilot-coding-agent.md`

For Copilot coding agents, the loop's key constraints are explicit: only ready work begins, claims are short and visible, merge trains hold included PRs, and the human owner authorizes merges and deploys.
