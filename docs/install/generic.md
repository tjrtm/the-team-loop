# Generic AGENTS.md

```bash
./install.sh --tool generic --target ../my-repo
```

The installer writes an `AGENTS.md` pointing to the full skill. For tools that do not discover skill folders, copy `skill/the-team-loop/SKILL.md` into the target repository and retain the generated `AGENTS.md` as the entry point.

The generic path needs only Git, GitHub CLI, Bash, and a human owner who can make direct decisions.
