# Cursor

```bash
./install.sh --tool cursor --target ../my-repo
```

The installer creates `.cursor/skills/the-team-loop/SKILL.md` and `.cursor/rules/the-team-loop.mdc`. The rule is always applied and points agents to the full skill.

If a repository uses existing Cursor rules, keep them. The loop governs collaboration and authorization; project rules continue to govern implementation.
